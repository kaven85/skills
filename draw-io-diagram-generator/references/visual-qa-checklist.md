# Visual QA checklist

After XML and geometry validation, export PNG or SVG with `scripts/export-preview.sh`. Inspect the whole page, every lane header, dense Port/Adapter regions, long routes or loops, and bilingual labels. Report: XML, lane overlap, node overlap, header intrusion, edge-through-node, manual waypoint count, bilingual sizing, and render status. If the CLI is unavailable, explicitly report `render: NOT RUN`.
